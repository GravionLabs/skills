# Group `school`

Skills of the `school` group and what each one does. Read before changing a skill of this group.

The group builds on the `vault` group (`vault-inbox` transcribes and files photos; `Get-VaultRoles.ps1` resolves the roles). All five skills read `school-summary/references/school-vault.md`: roles (`inbox`, `subjects`, `sources`, `exams`, `templates`; a topic is `<subjects>/<Subject>/<Topic>/` with the `sources` folder inside), the profile file (`files.profile`, default `Profile.md`; `name`, `grade`, `school_type`, `state`, subjects table; German spellings read too), file name patterns per language, and the rules of every note. Notes are written in the vault's `language` (a note's `lang` wins), default English; frontmatter keys stay English. Never delete or overwrite a note; solutions collapsed; additions beyond the class sources are marked.

`school-summary` (study summary of a topic; owns the shared reference and the profile assets `assets/en|de/`: `Profile.md`, `Exam.md`, `CLAUDE-school.md`, `folders.json` with the roles, for `/vault-setup school`), `school-timeline` (Mermaid timeline plus event table), `school-exercises` (exercises by difficulty level with collapsed solutions; further rounds are appended), `school-flashcards` (cards for the Spaced Repetition plugin; only new cards are appended), `school-exam` (exam note from the template with study plan, mock exam with collapsed marking scheme).
