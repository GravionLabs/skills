# Group `delivery`

Skills of the `delivery` group and what each one does. Read before changing a skill of this group. The public overview from Objective to release is `site/delivery/model.md`; keep it true to these skills.

`deliver/scripts/gates/` holds the gate scripts of ADR 0012. `gates/result.mts` is their shared contract (one JSON line `result`, `reason`, `evidence`; exit codes `pass` 0, `fail` 1, `usage` 64, `retry` 75, `owner` 77; `gateMain` in a script, `runGate`/`readResult` in an executor); `deliver/references/gates.md` has one row per script, and a new script adds its row.

`deliver-lead` (model-invocable, since a lead briefs another lead with it; triggers on lead requests only; `/deliver-lead <issue> [--run <run>]`, `help`; Feature #1142) routes the issue by type (PBI and Bug: `references/leaf.md`; Feature, Epic and milestone: not built yet; Objective: #1143), loads the adapter `host-<host>` and repeats: `step.mts`, the returned verb through the adapter, its outcome back as `--result`, until `end`. `leaf.md` names only the verbs of `host-verbs.md` and no host tool (test `deliver-lead-skill.test.ts`); a change of `Action` or `StepResult` in `leaf.mts` changes `leaf.md`.

`deliver-lead/scripts/` holds its step script: `step.mts leaf <issue> --run <run> [--result <file>]` (`leafStep` in `leaf.mts`) reads the run's agent-events, runs the gates of `deliver/scripts/gates/` in-process as their CLIs do and returns one action, a verb id of `deliver/references/host-verbs.md` or `end`; it never names a host tool. The events are its state: each one is written before the action it records is returned, `deliver.worker` keeps a worker's handle, and a repeated call with the same result returns the same action. Off the pass path each branch is a gate word: `changes` starts a fix round, `gone`, `error` or a missing verdict the same step again (both through `limits`), a `timeout` or a question waits within the session budget, `retry` a wait without handles, `owner` of guard, merge-approved or limits the loop's hand-over (`handover.mts`). Tests: `test/skills/delivery/deliver-lead-leaf.test.ts` with the scripted host `test/skills/delivery/deliver-lead/fake-host.mts`.
