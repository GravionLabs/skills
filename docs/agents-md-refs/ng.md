# Group `ng`

Skills of the `ng` group and what each one does. Read before changing a skill of this group.

`ng-implementation` (incl. `references/component.md`, `references/signal-store.md`; `references/helix.md`: Helix primitives instead of raw controls, read only when the project depends on `@gravionlabs/helix-ui`; `references/style-lint.md`: Stylelint token rules from the `setup-oxc-husky` template, for Helix projects the published preset `@gravionlabs/helix-lint` with Stylelint and the template check `helix/no-raw-control` in `pnpm lint` and the fast `checks`), `ng-test`, `ng-create-project`, `ng-ag-grid`, `ng-helix` (`@gravionlabs/helix-ui`: `references/components.md` with selectors, classes and inputs of Helix `release/next`, `references/recipes.md` for forms, dialogs, confirmations, path fields and row lists, `references/desktop.md` for the app shell, status bar and Tauri updates of `@gravionlabs/helix-desktop`, `references/migration.md` for the ordered migration from raw controls with the `helixAllow` allowlist phase, linking the setup of `style-lint.md`; points to the Helix UX rules and `docs/STYLEGUIDE.md`, copies no rule of `helix.md`). `skills-manage` adds `angular/skills` (`angular-developer`)
