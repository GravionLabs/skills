# Group `shared`

Skills of the `shared` group and what each one does. Read before changing a skill of this group.

dispatches to `<lang>-implementation`; `scripts/Format-Changed.ps1` formats the changed files with per-language default commands; override and `"format": false` in the `format` key of `.agents/config.json`;
