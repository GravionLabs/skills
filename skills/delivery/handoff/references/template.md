# Handoff template

```markdown
# Handoff: <title>

Date: <yyyy-mm-dd> · Branch: `<branch>` · Worktree: `<path>`

## Goal

One to three sentences. The focus of the next session first.

## State

- Done: <what, with commit SHAs or PR links>
- Not done / failing: <what, with the check or test that fails>
- Working tree: <clean | uncommitted files>

## Next steps

1. <concrete first action, command or file>
2. …

## Open decisions

- <question>: <options, recommendation>

## Suggested skills

- `<skill>`: <why>

## Pointers

- Issue/PR: #<nr>, <url>
- ADR/doc: `<path>`
- Files: `<path>:<line>`
- Commits: `<sha>`
```

An empty section holds `none`. Keep the document under about 80 lines.
