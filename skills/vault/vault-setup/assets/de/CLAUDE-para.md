## PARA-Vault

Die Notizen sind nach PARA geordnet: Projekte (mit Ende), Bereiche (laufend), Ressourcen (Nachschlagewerk), Archiv (abgeschlossen).

- Neues Material landet im Posteingang; `/vault-inbox` schlägt Ziele nach den Rollen vor und legt Freigegebenes ab.
- Eine Notiz gehört zu einem Projekt oder Bereich; alles Weitere mit `[[Wikilinks]]` verknüpfen.
- Abgeschlossene Projekte wandern ins Archiv und werden nie gelöscht.

| Befehl | Zweck |
| --- | --- |
| `/vault-inbox` | Import des Posteingangs vorschlagen, Freigegebenes ablegen |
| `/vault-clip <url>` | Seite ausschneiden |
| `/vault-summarize <Quelle>` | strukturierte Zusammenfassung |
| `/vault-meeting` | Besprechungsnotiz mit Aufgaben |
| `/vault-decision` | Entscheidungsprotokoll |
| `/vault-weekly-review` | Wochenrückblick |
| `/vault-recipe <Quelle>` | Rezeptnotiz (braucht die Rolle `recipes`) |
| `/vault-setup role <Name> <Pfad> [Beschreibung]` | Ordnerrolle setzen |
